# 💇‍♀️ Landing Page — Beauty Salon

Layout of a responsive landing page developed for a beauty salon. The project focuses on elegant design, performance, and accessibility.

---

## ✨ Some of the features

- **Fixed header with scroll effect** — the navigation bar changes appearance as you scroll the page
- **Responsive hamburger menu** — navigation adapted for mobile devices, closing when clicked outside
- **Scroll reveal** — elements appear with smooth animation as they enter the viewport
- **Scheduling form** — integrated with WhatsApp, with field validation and phone number mask
- **WhatsApp FAB** — floating quick contact button
- **Structured Schema.org** — JSON-LD markup for local SEO (`BeautySalon`)
- **Embedded map** — interactive Google Maps location display in HTML.

---

## 🛠️ Programming languages ​​used

- **Semantic HTML5** (ARIA roles, landmarks, labels)
- **CSS3** — custom variables, flexbox, grid, animations and media queries
- **Pure JavaScript** (Vanilla JS) — no dependencies External Files
